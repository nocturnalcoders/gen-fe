# Garuda Connect

Build a modern responsive community platform called "Garuda Empowerment Network". Design Style: - Modern SaaS - Clean UI - Blue, White, Gold accent - Glassmorphism - Rounded cards - Soft shadows - Mobile first - Accessible - Professional but warm - Similar quality to Circle.so, LinkedIn and Notion. The platform should contain the following modules. 1. Landing Page - Hero Section - Community Mission - Statistics - Testimonials - Upcoming Events - Mentor Highlight - Latest Articles - Call To Action 2. Community Dashboard - Personalized Feed - Upcoming Events - Active Mentorship - Recent Articles - Community Updates - Recommended Mentors 3. Mentorship - Browse Mentors - Mentor Profile - Request Mentorship - Active Mentorship - Session History - Progress Tracking - Goals 4. Community Articles - Publish Article - Rich Text Editor - Draft - Categories - Tags - Like - Comment - Bookmark - Share 5. ActiveGen This module is for community activities. Examples: - Football - Badminton - Hiking - Running - Coffee Meetup - Volunteering Each activity should have: - Event Banner - Date - Location - Organizer - Join Button - Participants - Discussion 6. Diaspora A community space for Indonesians living abroad. Features: - Country Chapters - Upcoming Gatherings - Networking - Career Sharing - Immigration Tips - Cultural Events 7. Community Events - Workshop - Webinar - Bootcamp - Offline Meetup - Hackathon Each event includes: - Registration - Speakers - Agenda - Countdown - FAQ 8. Member Directory - Search Members - Skills - Interests - Country - Company - LinkedIn - Contact 9. Notifications 10. User Profile - Bio - Skills - Experience - Articles - Events Joined - Mentorship Progress - Badges 11. Admin Dashboard - Manage Members - Manage Events - Moderate Articles - Analytics - Reports Create reusable React components and a clean design system with dark/light mode support.
